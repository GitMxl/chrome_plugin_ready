# 全部图片屏蔽

适用于 Chrome / Microsoft Edge 145 及以上版本的 Manifest V3 扩展。默认对所有网站开启，可在工具栏弹窗中随时关闭，设置会保存在本机。

## 安装

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择此文件夹（包含 manifest.json）。
4. 将扩展固定到工具栏，刷新已打开的网页。

## 按网站过滤

- **屏蔽所有网站，列表中的除外**：默认模式，列表为空时屏蔽所有网站；填入的网站正常显示图片。
- **仅屏蔽列表中的网站**：列表中的网站屏蔽图片，其他网站正常显示；空列表不屏蔽任何网站。
- 点击「添加当前网站到列表」，或在文本框中每行填写一个域名/HTTP(S) 网址，然后点击「保存网站列表」。删除对应行并保存即可移除网站。
- 例如 `example.com` 同时覆盖 `example.com`、`www.example.com` 和 `news.example.com`，不会覆盖 `notexample.com`。如只需覆盖某个子域名，请填 `news.example.com`。路径、端口和协议不用于区分网站；国际化域名会转换为标准编码。
- 当前最多支持 500 个网站；可使用域名、IPv4、localhost，暂不接受 IPv6 地址或通配符表达式（开头的 `*.` 可省略，会自动包含子域名）。
- 网络拦截和图片隐藏均按浏览器地址栏中的顶层网站判断，该页面的 CDN 图片及跨域 iframe 也遵循同一规则。
- 开关和模式切换会同时保存当前网站列表。切换模式会复用同一列表，列表含义随模式改变。
- 修改后刷新网页，确保被拦截的图片重新加载、网络规则及全部嵌入页面完整应用。总开关关闭时保留网站配置。
- 原版升级后仍默认屏蔽全部图片。更新扩展后请刷新已打开的网页。

## 图片布局

- **保留布局**（默认）：隐藏图片但保留原有占位，减少页面排版变化。
- **折叠空白**：普通图片不再占据原来的宽高，仅保留小型「显示图片」按钮；点击后恢复该图片及其占位。严格模式还会收起图片按钮和 SVG 图片元素。
- 布局选项保存在本机，兼容两档屏蔽强度、网站规则、嵌入页面及开放 Shadow DOM。切换布局会在已加载页面更新；关闭屏蔽或临时放行后不再折叠。
- 仅收起图片元素，不删除网站内容容器。容器的固定高度、最小高度、内外边距以及背景图容器可能仍会留下空白。

## 屏蔽强度

- **仅屏蔽普通图片**：隐藏普通 `img` 图片（包括 `picture` 中的图片），保留布局和单图查看按钮。背景图、图片按钮、SVG 图片及伪元素装饰保持原样；图片仍会下载，此模式不节省图片流量。以 `img` 实现的图标也会隐藏。
- **严格模式**：默认选项，保持原有行为，拦截图片网络请求，同时隐藏普通图片、图片按钮、SVG 图片以及背景、遮罩等装饰图片；可能影响图标和部分网站操作。
- 强度保存在本机，与网站列表、总开关和标签页临时放行配合生效。切换强度后请刷新网页，使此前拦截的背景图等重新加载。升级后仍默认严格模式。

## 临时查看图片

- 在弹窗中点击「临时放行当前标签页」，自动刷新并显示该标签页的图片，包括嵌入页面。其他标签页和网站列表不受影响。
- 临时放行在刷新、跳转和后台工作线程重启后保留；点击「取消当前标签页临时放行」会清除该标签页全部图片例外并自动刷新。关闭标签页或重启浏览器后失效。
- 屏蔽时，普通 `img` 图片位置会出现「显示图片」按钮，点击仅加载和显示选中的图片，不会打开图片链接；支持 data/blob 图片、响应式图片和可访问的开放 Shadow DOM。背景图、SVG 图片和图片按钮仍保持屏蔽。
- 单图网络例外按完整图片地址限定在当前标签页，保留到标签页关闭；同地址的请求也会获准，但其他图片元素仍隐藏。刷新页面后需重新点击显示。每个标签页最多保留 200 条单图例外，达到上限可使用临时放行。
- 响应式图片在查看后固定当前选中的版本。图片地址无效、服务器拒绝或重定向到其他地址时可能无法显示，可以重试或临时放行整个标签页。
- 图片位置过小或页面样式特殊时，查看按钮可能紧邻或覆盖周围内容；可使用弹窗中的临时放行查看完整页面。

## 权限说明

- `storage`：仅在本机保存开关、过滤模式、网站列表、屏蔽强度和布局选项。
- `declarativeNetRequest`：按顶层网站拦截图片请求；使用 Chrome 145 新增的顶层域名匹配规则。
- `activeTab`：用户打开弹窗时读取当前网站，用于显示网站状态和一键加入列表。
- 所有网站的内容脚本：在对应页面隐藏普通图片和背景图。

## 行为与范围

- 严格模式拦截浏览器识别为 image 类型的网络请求，减少图片下载；普通模式允许下载。
- 普通模式隐藏 img（含 picture 中的图片）；严格模式还隐藏图片按钮和 SVG 中的 image，移除 CSS 背景图、边框图片、列表图片和遮罩图片。图片占位由布局选项控制。
- 对动态添加的图片、可访问的 iframe 和已发现的开放 Shadow DOM 应用相同规则。
- 严格模式为屏蔽 CSS 伪元素图片，会隐藏 before/after 内容，部分装饰或图标可能随之消失。
- data/blob 图片通过页面样式隐藏。浏览器内置页面、扩展商店等受保护页面不能注入屏蔽样式。
- 不处理 canvas 内绘制的图片、内联 SVG 矢量图、视频画面、封闭 Shadow DOM，以及已挂载元素之后才创建且无 DOM 变动的 Shadow DOM。页面内具有更高优先级的样式可能覆盖隐藏规则。
- 关闭后刷新页面以重新下载图片。首次安装后也需要刷新已有页面。拦截不保证撤销已有缓存、预加载或已发出的请求。
- 网站列表只保存在本机，不上传浏览记录、网站列表及图片内容，不需要外部服务。

## 检查

运行 `node tests/check.mjs` 执行域名校验、网站范围、规则生成、开关、页面隐藏和弹窗操作回归检查。无需打包或构建，整个文件夹即可直接加载。

使用 Node.js 22+ 运行 `node tests/browser-check.mjs` 可在隔离的无头 Edge 中验证真实图片请求、跨域 iframe 及弹窗保存；可通过 `CHROME_PATH` 指定支持命令行加载扩展的 Chromium 浏览器。测试仅使用本地测试页面和临时浏览器配置，截图保存在 `tests/artifacts/site-filter-popup.png`。
